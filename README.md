# Rock Paper Scissors (Java)

A simple command-line Rock Paper Scissors game written in Java. Play against the computer, keep track of your score, and quit whenever you want.

## How to run

```bash
javac Main.java
java Main
```

## How to play

- When prompted, type `r` for Rock, `p` for Paper, or `s` for Scissors.
- The computer picks randomly each round.
- Type `X` at any point to exit and see your final score.

## Rules

- Rock beats Scissors
- Scissors beats Paper
- Paper beats Rock
- Same choice = tie, no point awarded

## Notes

This was built as a small practice project to work with loops, switch statements, and basic user input handling in Java. Nothing fancy, just a working game.

## Requirements

- Java JDK 8 or later
